# GreenField – Đặt phòng nghĩ dưỡng 
Website **đặt phòng** *nghỉ dưỡng* theo đêm .
| Thư mục | Nội dung |
|---|---|
| docs | Tài liệu khách sạn mây |
| data | Dữ liệu giao dịch |
| logs | Log truy cập website |

## Lệnh liệt kê dự án

```powershell
Get-ChildItem -Recurse -Force
```
